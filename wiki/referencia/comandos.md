# Lista de comandos

Casi todo funciona con prefijo (`!`, o el que configure el servidor) y con barra (`/`). Mencionar al bot funciona igual que el prefijo.

{% hint style="success" %}
En los comandos que apuntan a alguien, **responder a su mensaje** funciona igual que mencionarlo: por ejemplo, responderle con `!kiss`.
{% endhint %}

## Para todos

| Comando | Qué hace |
|---|---|
| `!casino` | Lobby del casino |
| `!balance [@x]` | Billetera |
| `!work [trabajo]` | Trabajar |
| `!daily` · `!weekly` · `!rescate` | Bonos |
| `!bj` `!ruleta` `!slots` `!crash` `!plinko` `!minas` `!pollo` `!globos` `!hilo` `!dragon` | Juegos |
| `!profile [@x]` | Perfil |
| `!top [categoría] [página]` · `!rank` | Rankings |
| `!stats [juego]` · `!history [juego]` · `!logros` | Estadísticas |
| `!fairness` | Juego justo |
| `!torneo [id]` | Torneos |
| `!marry @x` · `!divorce` | Casamientos |
| `!kiss @x` · `!besos` | Besos |
| `!avs` · `!banners` · `!names` | Historiales |
| `!steal` | Copiar emojis y stickers |
| `!premium` | Premium |
| `!ayuda` | Ayuda dentro de Discord |

## Staff del servidor

| Comando | Permiso | Qué hace |
|---|---|---|
| `/setup` | Administrador | Registros |
| `/ajustes` · `/prefijo` · `!setlang` | Gestionar servidor | Ajustes e idioma |
| `/voz` | Gestionar servidor | Voz temporal |
| `/roles` | Gestionar roles | Grupos de roles y distinciones |
| `/boosttracker` | Gestionar servidor | Mensajes de boost |
| `/automod` · `/anti-webhooks` | Gestionar servidor | Protección |
| `/mod` · `!warn` `!timeout` `!kick` `!ban` `!unban` `!modlogs` `!caso` | Moderación | Sanciones |
| `/purgar` · `!m @x 100` | Gestionar mensajes | Borrar mensajes de alguien |
