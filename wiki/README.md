# 🎰 El Valle Casino

**El Valle Casino** es un bot de Discord con un **casino virtual** (10 juegos con botones y animaciones), una economía difícil de farmear, torneos, perfiles con casamientos, canales de voz temporales, registros del servidor y moderación completa.

{% hint style="warning" %}
**Las Coins 🪙 son una moneda virtual del bot.** No se compran, no se retiran y no se cambian por dinero real ni por nada fuera del bot. Las apuestas, los premios y los torneos son solo un juego.
{% endhint %}

## ¿Qué trae?

| | |
|---|---|
| 🎰 **Casino** | Blackjack, Ruleta, Slots, Crash, Plinko, Minas, Pollo, Globos, Hilo y Dragon Tower |
| 🪙 **Economía** | Trabajos (`!work`), bonos, actividad, niveles, logros y ranking |
| 🏆 **Torneos** | Diarios y semanales automáticos, y especiales creados por el dueño |
| 👤 **Comunidad** | Perfiles, casamientos, besos, historiales de avatares y nombres, `!steal` |
| 🔊 **Voz temporal** | Cada persona crea su propio canal de voz con un panel de botones |
| 🛡️ **Moderación** | Casos, advertencias con escalado, automod, antiraid y anti-webhooks |
| 📋 **Servidor** | Registros, paneles de roles, mensajes de boost e idioma (español / inglés) |
