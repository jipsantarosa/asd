# Tu primera partida

1. **`!balance`** — mirá tu saldo. Empezás con **🪙 1.000**.
2. **`!work`** — trabajá para ganar unas Coins (ver [Trabajos](../casino/trabajos.md)). También tenés **`!daily`** y **`!weekly`**.
3. **`!casino`** — el lobby con todos los juegos. Elegí uno en el menú para ver sus reglas.
4. **Apostá:**

```
!ruleta 100 rojo
!crash 200 2x
!minas 50 3
!bj 100
```

5. Al terminar, tocá **🔁 Repetir** para jugar otra igual, o **×2** / **½**.

## Cómo escribir la apuesta

| Escribís | Apuesta |
|---|---|
| `500` o `1.000` | ese número |
| `1k`, `2.5k`, `1m` | 1.000, 2.500, 1.000.000 |
| `mitad` | la mitad de tu saldo |
| `todo` | todo tu saldo (hasta la apuesta máxima del juego) |

{% hint style="info" %}
Escribí el nombre de un juego **sin apuesta** (por ejemplo `!crash`) para ver sus reglas, la tabla de pagos y los límites.
{% endhint %}

{% hint style="warning" %}
Las Coins son difíciles de conseguir a propósito. Jugá por diversión: es una moneda virtual.
{% endhint %}
