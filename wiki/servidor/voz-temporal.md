# Canales de voz temporales

1. Un admin usa **`/voz`** → **Configurar / reparar**: crea la categoría **・creator**, el canal **・Crear Voice** y **・interface**.
2. Al entrar a **・Crear Voice**, el bot crea **tu canal** y te mueve ahí.
3. Cuando queda vacío, se borra solo.

## Panel

Desde el canal de interfaz, el chat de tu canal o `/canal`:

| | | | | |
|---|---|---|---|---|
| ✏️ Nombre | 👥 Límite | 🔒 Privado | 👻 Ocultar | 🌍 Región |
| ✅ Permitir | ➖ Quitar acceso | 📨 Invitar | 👢 Expulsar | ℹ️ Info |
| 🚫 Bloquear | ♻️ Desbloquear | 👑 Reclamar | 🔁 Transferir | 🗑️ Eliminar |

* Tus preferencias se guardan para la próxima vez.
* Si quien creó el canal se va, cualquiera adentro puede **👑 Reclamar**.
* Discord solo deja renombrar un canal 2 veces cada 10 minutos.

## Admins

* **Nombre y límite** por defecto (`{usuario}` = nombre de quien lo crea).
* **Configurar / reparar** también actualiza los canales sin duplicar, deja un solo panel, y ofrece **🧹 Borrar sobrantes** (salas huérfanas vacías, paneles repetidos). Las salas con gente nunca se tocan.
