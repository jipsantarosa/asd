# Historiales y !steal

## Historiales

| Comando | Qué muestra |
|---|---|
| `!avs @usuario` | Avatar actual e historial de avatares que el bot vio |
| `!banners @usuario` | Lo mismo con el banner |
| `!names @usuario` | Historial de @usuario, nombre visible y apodos |

{% hint style="info" %}
El historial es solo lo que el bot detectó desde que está en el servidor: no inventa cambios anteriores.
{% endhint %}

## !steal

Copia emojis o stickers de un mensaje a tu servidor.

* Respondé a un mensaje con **`!steal`**, o pegá los emojis: `!steal <:pepe:123…> [nombre]`.
* También: clic derecho en el mensaje → **Apps** → **Robar emoji o sticker**, o `/steal`.
* Si hay varios, aparece un menú para elegir hasta 10.

Requiere el permiso **Crear expresiones** (vos y el bot). Respeta los lugares libres según el nivel de mejoras del servidor. Los stickers **Lottie** y los oficiales de Discord no se pueden subir (Discord no lo permite).

{% hint style="warning" %}
Copiá solo emojis y stickers que tengas permiso de usar.
{% endhint %}
